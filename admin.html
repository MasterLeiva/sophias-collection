Se guarda solo en este navegador. Úsala únicamente en tus dispositivos.

¿Cómo creo mi clave?
  1. Entra a github.com/settings/personal-access-tokens/new con tu cuenta de GitHub.
  2. Token name: “Admin tienda”. Expiration: la más larga que permita.
  3. Repository access: “Only select repositories” y elige el repositorio de la tienda.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Toca Generate token, cópialo y pégalo aquí.
